About Gary's Reloading Tool

An interior-ballistics estimator that runs entirely in your browser. Nothing is uploaded; save this page (or the whole folder) and it works offline.

  • Pick an example load, or a caliber, bullet and powder. Every value can be edited.
  • Open reads .grtload, .caliber, .projectile and .propellant files (you can also drag and drop them). Save downloads the current load.
  • Ladder: set the steps (2–10) and step size to compare reduced charges. Click a step to highlight it.
  • Built-in data comes from the community GRT database collection (github.com/zen/grt_databases, CC0).

Safety: results come from a simplified model and can be wrong by a wide margin. Never use them as load data. Always start from published manufacturer data, measure your own case volume and bullet length, and work up carefully.
